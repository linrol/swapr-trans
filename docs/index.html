快速安装与授权

  • 01 下载 SwaprTrans-1.0.2.dmg 并将 App 拖拽至 Applications；
  • 02 首次打开：若遇 Gatekeeper 提示，在访达中右键点击 App → 点击「打开」；
  • 03 按系统提示授予「辅助功能」(Accessibility) 权限，即刻开启选词原地覆写体验；

常见问题解答 (FAQ)

了解 SwaprTrans 的工作原理、隐私安全保障与核心用法

✦ SwaprTrans 的「原地覆写」是如何工作的？

在任意聊天框（Teams/Slack/微信）、邮件或终端中输入文字后，划选文字敲击空格键（默认触发键）唤起轻量翻译浮窗；确认译文后轻敲回车键，原文瞬间原子级替换为地道译文，光标与上下文完美保持，无需切屏和反复复制粘贴。

 Apple 原生端侧模型是否支持脱网离线翻译？

完全支持。在 macOS 15+ (Sequoia) 系统中，SwaprTrans 深度集成了 Apple 官方 Translation.framework 与 Neural Engine 神经引擎。在系统设置中下载本地离线语言包后，完全断网即可秒速离线推理，100% 隐私安全，机密沟通绝不上云。

⌨️ 是否支持修改默认快捷键？

支持。默认触发快捷键为空格键（Space），同时在设置面板中预设了右键双击、方向键向下、Option + D、Option + T、Option + Space、F1 ~ F6 等多种高效手势与组合键，用户可按个人习惯自由选择。

📦 第三方开发者如何集成 SwaprTrans？

SwaprTrans 的核心能力已拆解封装为 SwaprTransKit，作为 Swift Package (SPM) 完全开源。开发者只需在 Package.swift 中引入依赖，即可在自己的 macOS 原生 App 中开箱即用集成划词瞬译与原地覆写能力。

⭐ 收藏的生词如何查看、搜索与导出？

在菜单栏下拉面板中点击「Saved Translations」即可唤起独立的生词管理窗口。支持对原文与译文进行实时模糊检索、原声发音朗读，并支持一键导出为标准的 CSV 或 JSON 格式，方便无缝同步至 Anki、欧路词典等外部学习工具。
